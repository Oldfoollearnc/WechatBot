# 排序小助手 🐷

**猪猪工作室出品** - 微信小程序自动化操作工具

## 这是什么？

排序小助手是一款 Windows 桌面自动化工具，专门用于自动执行微信小程序「排序小助手」的重复操作流程。

通过**图像识别技术**，程序可以自动识别屏幕上的按钮和元素，并按照预设步骤自动点击，无需人工干预。

## 解决什么问题？

### 痛点场景

如果你需要：
- 每天重复执行「创建排序 → 复制排序 → 分享到群」的操作
- 批量处理多个抽奖活动
- 定时自动完成任务

手动操作不仅**枯燥耗时**，还容易**出错遗漏**。

### 解决方案

排序小助手帮你：
- ✅ **解放双手** - 一次配置，自动执行
- ✅ **准确无误** - 图像识别精确匹配
- ✅ **定时运行** - 设定时间自动完成
- ✅ **全程记录** - 详细日志可追溯

## 执行流程

程序按照以下 14 个步骤自动执行：

```
┌─────────────────────────────────────────────────────────────┐
│  1. 小程序面板    → 点击微信左侧小程序入口                    │
│  2. 排序小助手    → 选择「排序小助手」小程序                  │
│  3. 跳过广告      → 点击广告页「跳过」按钮                    │
│  4. 我的          → 进入「我的」页面                          │
│  5. 创建的排序    → 打开「创建的排序」列表                    │
│  6. 第一个抽奖    → 选择第一个抽奖项目                        │
│  7. 排序管理      → 进入「排序管理」                          │
│  8. 复制排序      → 点击「复制排序」（自动滚动）              │
│  9. 确定(第一次)  → 确认复制操作                              │
│ 10. 确定(第二次)  → 再次确认                                  │
│ 11. 分享          → 点击「分享」按钮                          │
│ 12. 分享好友      → 选择「分享好友」                          │
│ 13. 目标群        → 选择要发送的目标群                        │
│ 14. 发送          → 点击「发送」完成                          │
└─────────────────────────────────────────────────────────────┘
```

## 工作原理

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   屏幕截图   │ ──→ │   图像匹配   │ ──→ │   模拟点击   │
└──────────────┘     └──────────────┘     └──────────────┘
                            │
                            ▼
                     ┌──────────────┐
                     │  找到目标？  │
                     │  是 → 点击   │
                     │  否 → 重试   │
                     └──────────────┘
```

1. **截取模板** - 用户框选屏幕上的按钮/元素作为识别模板
2. **屏幕识别** - 程序实时截屏，与模板进行图像匹配
3. **自动点击** - 找到目标位置后，自动执行鼠标点击
4. **步骤推进** - 完成一步后，自动进入下一步

## 核心功能

### 📋 步骤管理
- 可视化配置每个步骤的识别模板
- 支持截取、测试识别、重置操作
- 实时显示配置进度

### 🚀 自动执行
- 一键运行全部步骤
- 支持测试模式（最小化窗口后执行）
- 随时停止中断任务

### ⏰ 定时任务
- 设置每日自动执行时间
- 支持按星期几执行
- 自动跳过已完成的任务

### 📊 运行日志
- 详细记录每步执行结果
- 支持按级别筛选（INFO/WARN/ERROR）
- 支持文本搜索

### 🎨 主题切换
- 深色主题 - 护眼暗色调
- 浅色主题 - 明亮清爽风格
- 运行时一键切换

### 🪟 悬浮状态窗
- 运行时屏幕右下角显示状态
- 实时显示当前执行步骤
- 不遮挡其他窗口操作

## 使用教程

### 第一步：配置模板

首次使用需要为每个步骤配置识别模板：

1. 打开应用，进入「步骤」页面
2. 确保微信小程序已打开并显示对应界面
3. 点击步骤右侧的「截取」按钮
4. 框选屏幕上的目标元素（如按钮）
5. 重复以上步骤，直到全部配置完成

> 💡 **提示**: 模板截取要精确，只包含目标元素，不要包含多余背景

### 第二步：测试识别

配置完成后，可以测试识别效果：

1. 点击「识别」按钮
2. 程序会在屏幕上标记识别结果
3. 确认识别准确无误

### 第三步：运行任务

配置完成并测试通过后：

1. 回到「首页」
2. 点击「开始运行」或「测试运行」
3. 程序将自动执行全部步骤

### 第四步：定时执行（可选）

如需每日自动执行：

1. 进入「设置」页面
2. 勾选「启用定时执行」
3. 设置执行时间（如 10:00）
4. 选择执行日期（如周一到周五）
5. 点击「保存设置」

## 常见问题

### Q: 识别不准确怎么办？
A: 重新截取模板，确保：
- 只截取目标元素，不要包含多余背景
- 避免截取会变化的内容（如数字、时间）
- 在目标清晰可见时截取

### Q: 程序运行时可以操作电脑吗？
A: 可以。程序运行时会显示悬浮状态窗，你可以正常使用电脑，但避免：
- 移动或最小化微信窗口
- 切换到其他全屏应用

### Q: 支持多显示器吗？
A: 支持。截取模板时，目标元素需要在主显示器上可见。

### Q: 如何更新程序？
A: 从 GitHub 下载最新版本，替换原文件即可。配置会自动保留。
